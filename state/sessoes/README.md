# Registros de sessão

Um arquivo por sessão: `NNN-nome-curto.md`, numeração sequencial de três
dígitos. É aqui que mora o **histórico** — o `STATE.md` guarda só o estado de
agora.

Criados pelo `/session-close`; o modelo está em
`.claude/skills/session-close/references/persistencia.md`.

Curtos e de alto sinal. Se um registro passar de uma tela, provavelmente é
documentação disfarçada e pertence a `docs/`.

As sessões anteriores a 2026-10-01 (etapas E0 a E8 e a janela turbo) não têm
registro aqui: a convenção começou depois. O histórico delas está no
`STATE.md` e no `git log`.
